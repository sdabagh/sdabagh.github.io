# Learn Without Walls

Source of [learnwithoutwalls.com](https://learnwithoutwalls.com): free, open courses in mathematics, statistics, Python,
data science, AI and financial literacy, built by Safaa Dabagh (mathematics and statistics instructor at Santa Monica
College, PhD candidate in Statistics at UCLA). Plain HTML, CSS and JavaScript on GitHub Pages; no accounts, no tracking.

- **Courses**: `learn/` holds every course (college algebra, statistics, calculus, linear algebra, differential equations,
  Python and SQL labs, financial literacy, AI certificates, research methods, courses for young learners and more).
  `free-courses.html` is the catalogue.
- **Stats Without Walls**: `stats/` is a browser-only statistical tool (descriptives to MANOVA, probability calculators,
  classroom demonstrations, a sensitivity analysis for lurking variables). Open [learnwithoutwalls.com/stats](https://learnwithoutwalls.com/stats/).
  Its own README and user guide are in that folder.
- **Instructor packs**: `instructor/` has ready-to-teach materials (slides, worksheets, cheat sheets).
- **Research**: `publications.html` and `participate.html` describe the dissertation study on AI-powered cognitive
  scaffolding for statistics education.

Everything here is free to use in teaching. Datasets in `stats/data/` carry their sources in the README there.
