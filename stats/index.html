Start here.
  1. Data: open a CSV from your computer, paste from a spreadsheet, or pick a sample dataset.
  2. Exploration: Descriptives, with the plots, exactly as in jamovi. Graph: bar, pie, histogram, dotplot, boxplot, stem and leaf, scatter, QQ, StatCrunch style, each with Group by.
  3. T-Tests, ANOVA, Regression, Frequencies: the same menus and options as jamovi, so the course instructions work as written. Every result adds the formula, the decision, the sentence to write, and a condition check.
  4. distrACTION: binomial, normal, t, chi-square and F, built in, nothing to install.
  5. Learn: a sampling distribution simulator for the Central Limit Theorem.
Means always use t with degrees of freedom (the population standard deviation is never given). Decisions use the p-value approach. There is no inference about a variance in this course, so there is none here. Your data stays on this computer, and the page keeps working with no internet once it has loaded. To install it like an app: in Chrome or Edge use the install icon in the address bar; in Safari on a Mac use File, then Add to Dock.
